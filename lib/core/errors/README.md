# Errors

This directory contains custom exception and failure handling logic.

## Purpose
- `exceptions.dart`: Classes representing unexpected runtime situations (e.g., `ServerException`, `CacheException`).
- `failures.dart`: User-facing error representations (e.g., `ServerFailure`, `NetworkFailure`).
